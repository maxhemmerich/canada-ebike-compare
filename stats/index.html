What is counted, and what is not

  1. Counted: one anonymous increment per page load, fired by a few lines of script that every page on this site carries. The counter names the page, and nothing else.
  2. Not counted: any visitor with JavaScript switched off — and counted: any software that loads a page and runs scripts, crawlers included. These numbers are a floor, not a census; a small number is not proof that nobody looked.
  3. What leaves a visitor's browser: one plain GET carrying no cookie (credentials: omit), no referring page (referrerPolicy: no-referrer) and no identifier of any kind. A counting service, like any web server, necessarily sees the requesting IP address; nothing else about a visitor is sent or stored.
  4. Where the numbers live: the counters are kept by Abacus, a free counting API that needs no account, no signup and no key, under the namespace maxhemmerich.github.io. Every row above reads its own key back the same way, and any value is a plain address you can open yourself — for example this site's landing-page counter, https://abacus.jasoncameron.dev/get/maxhemmerich.github.io/canada-ebike-compare-index. Every key on this page is a real counter that a page on this site fires when it loads; there is no placeholder. It is a third party with no uptime promise: where it cannot be reached, the rows above say so rather than showing a zero. It also allows only 30 reads per 10 seconds per address, and this page reads 15 counters — so it reads them one at a time, about two a second, and waits out a rate-limited read instead of calling the counter dead.
  5. Nothing is sold, profiled or shared. There is no analytics product here, no cross-site tracking and no attempt to identify anyone. The only use made of these numbers is knowing whether this site is being read.
